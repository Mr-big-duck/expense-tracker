# 记账系统（money）

一个命令行记账工具：记一笔、看账本、按日期算账。

## 用法

```bat
:: 记一笔（性质默认「消费」）
python money.py add 35.5 餐饮 "和同学吃火锅"

:: 记一笔，指定性质
python money.py add 60 食品 "泡面一箱" --kind 囤货

:: 看全部账本
python money.py list

:: 统计某一天
python money.py stat 2026 11 17

:: 统计某段时间
python money.py stat 2026 11 16 2026 11 18
```

## 特性

- **一笔账五个字段**：日期、金额、分类、备注、性质
- **按性质区分"钱去哪了"**：消费 / 囤货 / 投资 / 固定
- **重名不覆盖**：账本是追加写入，历史不会丢
- **按日/区间统计**：自动汇总每天的花费和各类占比
- **出错不崩**：金额不是数字、参数不够、命令打错，都只提示不退出

## 环境

- Python 3.10+
- 只用标准库：`json`、`sys`、`pathlib`、`datetime`、`argparse`

## 数据格式

`data.json` 是一个列表，每条账记录长这样：

```json
{
    "date": "2026-11-17",
    "amount": 250.0,
    "category": "购物",
    "note": "买了个冰箱",
    "kind": "投资"
}
```
